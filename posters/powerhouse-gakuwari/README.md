## 設計方針
- 学生のジム選びは「通いやすさ」→「料金」の順で重視 → 価格を最大、次に駅徒歩・利用時間
- 3m先から読める順に情報を3段階に絞る：①月額2,980円 ②おトク額・1日約99円 ③0円/時間/見学
- 大学は許可印・団体名・問い合わせ先の明記を求めることが多い → 右上に許可印欄、下部に名称・住所・電話
- 掲示サイズ上限はB4〜A3の大学が多い → A3で作成、縮小してもQR・電話番号が読めるサイズ
- 行動は1つに絞る：「学生証を持って、まずは見学へ」＋電話＋QR（公式サイト）

- 学校の向かいという立地を外観写真＋看板の囲みで見せ、「授業の前後にそのまま寄れる」を伝える
- 上部に館内写真を置き、本格的なマシンがそろっていることを一目で伝える
