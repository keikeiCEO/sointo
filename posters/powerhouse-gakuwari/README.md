# パワーハウスジム札幌ジャパン 学割プラン 学校掲示用ポスター

- `poster_A3.pdf` … 入稿・印刷用（A3縦、文字はベクター）。A4/B4/A2 に拡大縮小しても比率は同じ
- `poster_A3.png` … メール添付・確認用（約290dpi相当）
- `poster.html` / `qr.png` … 編集用ソース（フォントは Google Fonts の Noto Sans JP / Anton / Oswald）

## 設計方針
- 学生のジム選びは「通いやすさ」→「料金」の順で重視 → 価格を最大、次に駅徒歩・利用時間
- 3m先から読める順に情報を3段階に絞る：①月額2,980円 ②おトク額・1日約99円 ③0円/時間/見学
- 大学は許可印・団体名・問い合わせ先の明記を求めることが多い → 右上に許可印欄、下部に名称・住所・電話
- 掲示サイズ上限はB4〜A3の大学が多い → A3で作成、縮小してもQR・電話番号が読めるサイズ
- 行動は1つに絞る：「学生証を持って、まずは見学へ」＋電話＋QR（公式サイト）

## 要確認
- 一般会員料金：添付原稿は 7,678円、公式サイト検索結果では 7,700円表記あり
- 公式サイトでは24時間営業の記載あり。学割の利用時間 7:00〜23:00 で正しいか
- QRの遷移先は https://phg-sapporo-japan.jp/ （LINE・見学予約ページがあれば差し替え推奨）
