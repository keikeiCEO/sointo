# パワーハウスジム札幌ジャパン 学割プラン 学校掲示用ポスター

- `poster_A3.pdf` … 入稿・印刷用（A3縦、文字はベクター）。A4/B4/A2 に拡大縮小しても比率は同じ
- `poster_A3.png` … メール添付・確認用（約290dpi相当）
- `poster.html` ほか画像（`logo.png` `interior.jpg` `exterior.jpg` `qr.png`）… 編集用ソース（フォントは Google Fonts の Noto Sans JP / Anton / Oswald）

## 設計方針
- 白地・黒文字・ロゴの赤の3色だけ（白6：黒3：赤1）。カラフルな掲示物が多い掲示板で、余白の多い紙面はかえって目立ち、プリンタでも刷りやすい
- 写真を大きく、加工なしで載せる。館内の実物の雰囲気がいちばんの説得材料
- ジャンプ率を高くする：赤の「2,980」が最大、ほかの情報は小さく控えめに
- 視線はZ型：ロゴ → 写真 → 見出し・価格 → 3つの条件 → 外観・電話・QR
- 外観写真で「この学校の向かいのビル6階」を伝え、行動は「学生証を持って見学へ」の1つに絞る
- 名称・住所・連絡先は下部に明記（大学は団体名・連絡先の明記を求めることが多い）
